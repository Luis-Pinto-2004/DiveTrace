# DriveTrace Core Dashboard

Vue 3 + TypeScript + Vite frontend for the DRIVOLUTION WP3 WIP traceability demo.

```bash
npm install
npm run dev
```

Default API URL: `http://localhost:5181/api`. Override it with `VITE_API_URL`.
Grafana embed base URL: `http://localhost:33010`. Override it with `VITE_GRAFANA_BASE_URL`.
